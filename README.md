# Swiss German Vocab

A vocabulary trainer for learning to understand Swiss German (Zurich dialect). The app is meant for people who are new to German-speaking Switzerland or want to understand Swiss German better. The focus is on everyday expressions, not just single words.

Created in the Code Kitchen module at FHNW, HS26.

## Features (planned)

- Browse words by category
- List with a detail view for each word
- Flashcard mode
- Learning progress based on the Leitner system
- Progress per category
- Add and edit your own words
- Saving in the browser (localStorage)

## Tech

- HTML, CSS and vanilla JavaScript, no frameworks or libraries
- Model, View, Controller architecture with custom observables
- Word list stored as JSON, learning progress in localStorage
- Hosted on GitHub Pages, no backend
